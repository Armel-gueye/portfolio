# Job Offer Aggregator

## Multi-Source Job Collection Automation — In Progress

This project is an ongoing automation system for collecting and organizing job offers from multiple sources.

The goal is to transform heterogeneous job listings into a consistent dataset and automate the steps between collection, processing, storage, and notification.

## Planned / Implemented Pipeline

```text
Job Sources
    ↓
Collection
    ↓
Normalization
    ↓
Filtering
    ↓
Deduplication
    ↓
Structured Storage
    ↓
Notification
```

## Current Focus

- Collecting offers from multiple source types
- Normalizing title, company, location, description, link, dates, and source metadata
- Filtering and relevance processing
- Deduplication
- Structured storage with n8n Data Tables
- Notification workflow

## Current Status

**In progress**

This project is intentionally documented as work in progress rather than as a finished production system.
